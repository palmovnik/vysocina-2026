Mapy.cz URL

With the URL function of Mapy.com, you can easily construct URLs that Mapy.com understands (both the website and mobile application). By calling this URL, you trigger a selected function (map display, search, planning, etc.).

Thanks to these URLs, you can easily launch/open Mapy.com from your website or application. Calling it on the web opens the Mapy.com website. Calling it on mobile launches the Mapy.com mobile application (if installed, otherwise the web version).

Prefix for all URLs: https://mapy.com/fnc/v1

Mapy.com URLs are freely available. They do not require an API key for their invocation.

/showmap

This function is used to set the map display at defined coordinates and to display a point.

Parameters:

Examples:

  • https://mapy.com/fnc/v1/showmap
  • https://mapy.com/fnc/v1/showmap?mapset=winter
  • https://mapy.com/fnc/v1/showmap?mapset=winter&center=14.4203523,50.0313731
  • https://mapy.com/fnc/v1/showmap?mapset=winter&center=14.4203523,50.0313731&zoom=16
  • https://mapy.com/fnc/v1/showmap?mapset=winter&center=14.4203523,50.0313731&zoom=16&marker=true

/search

This function is used to display search results.

Parameters:

Examples:

  • https://mapy.com/fnc/v1/search
  • https://mapy.com/fnc/v1/search?query=restaurace
  • https://mapy.com/fnc/v1/search?query=restaurace&mapset=outdoor
  • https://mapy .com/fnc/v1/search?query=restaurace&mapset=outdoor&center=14.4203523,50.0313731
  • https://mapy.com/fnc/v1/search?query=restaurace&mapset=outdoor&center=14.4203523,50.0313731&zoom=16

/route

This function is used to display planned routes.

Parameters:

Examples:

  • https://mapy.com/fnc/v1/route
  • https://mapy.com/fnc/v1/route?mapset=traffic
  • https://mapy.com/fnc/v1/route?mapset=traffic&start=14.4606,50.0878
  • https://mapy.com/fnc/v1/route?mapset=traffic&end=14.3681,50.0292
  • https://mapy.com/fnc/v1/route?mapset=traffic&start=14.4606,50.0878&routeType=car_fast_traffic
  • https://mapy.com/fnc/v1/route?mapset=traffic&end=14.3681,50.0292&routeType=car_short
  • https://mapy.com/fnc/v1/route?mapset=traffic&start=14.4606,50.0878&end=14.3681,50.0292
  • https://mapy.com/fnc/v1/route?mapset=traffic&start=14.4606,50.0878&end=14.3681,50.0292&routeType=car_fast_traffic
  • https://mapy.com/fnc/v1/route?mapset=traffic&start=14.4606,50.0878&end=14.3681,50.0292&routeType=car_fast_traffic&waypoints=14.5087,50.0335
  • https://mapy.com/fnc/v1/route?mapset=traffic&start=14.4606,50.0878&end=14.3681,50.0292&routeType=car_fast_traffic&waypoints=14.5377,50.0831;14.5087,50.0335
  • https://mapy.com/fnc/v1/route?mapset=traffic&start=14.4606,50.0878&end=14.3681,50.0292&navigate=true
  • https://mapy.com/fnc/v1/route?mapset=traffic&start=14.4606,50.0878&end=14.3681,50.0292&routeType=car_fast_traffic&waypoints=14.5377,50.0831;14.5087,50.0335&navigate=true
